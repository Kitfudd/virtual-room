## Conventions

- Diagrams are [Mermaid](https://mermaid.js.org/) blocks, so they render on GitHub and diff as text.
- Dates are ISO 8601 (`2026-11-13`).
- Low-fidelity wireframes and reference images are not included in the repository: the wireframes in a private design file, the references in the ignored `art/reference/` folder.
